# Arka Bhattacharya's French B SL class

This package contains the complete static source of the published French classroom demo, including student and teacher views, grammar notes, two course units, French audio and images.

## Publish on GitHub Pages

1. Extract this ZIP on your computer.
2. Create a public GitHub repository, for example Arka_French_Demo.
3. Open the repository and select Add file > Upload files. In a new empty repository, you may see an "uploading an existing file" link instead.
4. Drag the extracted index.html, styles.css, course.js, app.js, assets folder and README.md into the upload area. Keep the assets folder intact. The index.html file must be in the repository's top level.
5. Commit the files to the main branch.
6. Open Settings > Pages.
7. Under Source, choose Deploy from a branch. Choose main and /(root), then Save.
8. Open the site link displayed by GitHub once deployment finishes.

The package includes an empty .nojekyll file. If your file manager hides it, you can create a file named .nojekyll directly in GitHub using Add file > Create new file.

## Included files

- index.html — interface, class branding and source information
- styles.css — responsive layout and fonts
- course.js — the two units, grammar notes and timed practice content
- app.js — quizzes, drafts, assignments, corrections, oral recording and progress
- assets/ — two images and three French audio files
- .nojekyll — static publishing marker
- README.md — these instructions

## Using the demo

Use Élève and Enseignant to switch views. The teacher dashboard can be opened with #professeur/apercu appended to the published site address. The student view is at the main address.

Profiles and sample results are fictitious. Assignments, drafts, comments and progress are saved in the visitor's browser. Different devices and browsers have separate data. Data from the original hosting address does not transfer to GitHub Pages.

Oral recording requires a supported browser and microphone permission. Recordings remain available during the page session. The listening audio files are included in this package.

The site uses Google Fonts with fallback fonts available if the font service cannot load. It requires no build process or API keys.

## Content

French B SL practice is designed for the 2027–2028 examination sessions. The two units follow the topics and activity approaches in chapters 1A and 1B of French B Course Companion, Christine Trumper and John Israel, second edition, Oxford University Press, 2018. The demo's passages, exercises, examples, images and audio are original.

The grammar section adapts the class notes supplied for Arka Bhattacharya's class.
